# Fallout: New Vegas Vanilla DLAA Host v1.0.1

1. Extract `FNV-Vanilla-DLAA-v1.0.1.zip` into the folder containing
   `FalloutNV.exe`.
2. Copy `nvngx_dlss.dll`, `nvngx_dlssnr.dll`, and
   `renodx-dlss5.addon64` directly into `.trex`.
3. Run `PLAY-FNV-DLAA.bat`.

The ZIP does not contain the two NVIDIA DLLs or the RenoDX addon. Obtain
compatible signed NVIDIA DLLs and obtain the addon from a source you trust.
Do not substitute `nvngx_dlssg.dll`.
